# 1. DermaAI - Acne Detection

This part focuses on detecting acne from facial images using:
- **YOLO (You Only Look Once)**: object detection framework used for real-time lesion localization. The model predicts bounding box coordinates and confidence scores in a single forward pass, ensuring efficient processing of facial images.
- **CNN (Convolutional Neural Networks)**: TBD

# 2. Conda Environment Setup

You can use Conda to manage dependencies for the ML part of the project.

---

## Create environment

Make sure you are where `Models/` is located, then in the terminal:

```bash
conda env create -f environment.yml
```
---
## Activate environment
```bash
conda activate acne-detection
```
---

If `environment.yml` changes:

```bash
conda env update -f environment.yml --prune
```
---
## Remove environment (optional)
```bash
conda remove --name acne-detection --all
```

# 3. VS Code Setup (Interpreter Selection)

To ensure the project runs correctly, VS Code must use the Conda environment created for this project.

---

## Select Python interpreter
1. Press `Ctrl+Shift+P`.
2. Type `Python: Select Interpreter`.
3. Choose the one labeled `acne-detection`.

---

## Important notes
1. **RUNNING**: Always run scripts from the Terminal.
2. **INTERPRETER**: Ensure the correct Conda/Env interpreter is active in VS Code. If imports fail, your terminal is likely using the wrong Python version (you need to type `conda activate acne-detection` in terminal). 
3. **STRUCTURE**: This script MUST include a `if __name__ == "__main__": main()` block to handle multiprocessing and path initialization correctly.
4. **GIT/REPO**: 
    - DO NOT upload datasets to the repository.
    - DO NOT upload trained models (.pt, .h5) to GitHub (they are too large) we will solve it later.

## 4. Directory Structure & Workspace

| Directory | Purpose |
| --- | --- |
| **`Models/yolo/src/`** | Contains executable scripts (`train.py`, `predict.py`, `validate.py`, `merge_pipeline.py`) |
| **`Models/yolo/data/`** | Raw datasets from Roboflow and Kaggle |
| **`Models/yolo/data/dataset_final_preprocessed/`** | **Dynamic.** Unified dataset generated by the merge pipeline |
| **`Models/yolo/weights/`** | Store your `.pt` files here. `predict.py` looks for `best_{CURRENT_VERSION}.pt` here |
| **`Models/yolo/images/raw/`** | Input folder for testing. Put your photos here for inference |
| **`Models/yolo/runs/`** | Auto-generated outputs, logs, HPO results, and detection images |
| **`Models/yolo/notebooks/`** | Analysis and HPO history for each model version |

---

### Configuration (`config.py`)

The system uses a central configuration file to manage versions and paths:

* **`CURRENT_VERSION`**: Set this to switch the entire pipeline to a specific model version (e.g. `"v3.2"`).
* **`BEST_MODEL`**: Automatically points to `weights/best_{CURRENT_VERSION}.pt`.
* **`CONF_THRESHOLD`**: Set it yourself for sensitive detection. Any detection with a confidence score below this threshold is automatically discarded and excluded from prediction.

# 5. Pipeline Execution

Follow these steps in order to build, train, and use the acne detection model.

### 5.1 For versions v1 and v2: 
#### Data Preparation (`merge_datasets.py`)

**Command:** `python Models/yolo/src/yolo_dataset_merge_pipeline.py`

* **Pre-requisite (Data Acquisition):** Download datasets (listed in config.py) in **YOLOv8 format** and place them into `Models/yolo/data/`

* **What it does:** Scans raw datasets, removes visual duplicates (pHash), and merges everything into a clean `dataset_final/` folder.
* **Merge Strategies:** 
    * `[0] Standard`: Keeps all images.
    * `[A] Scenario A`: Strict uniqueness (prioritizes Train).
    * `[B] Scenario B`: Leak-free (removes Train-duplicates from Val/Test). **Highly Recommended.**

### 5.1 For versions v3.2:

#### 5.1.1 Data Preparation (`build_dataset_from_scratch.py`)

**Command:** `python Models/yolo/src/yolo_dataset_preparation_pipeline.py`

* **Pre-requisite (Data Acquisition):**  
**JSON Annotations:** Download from the [AIpourlapeau GitHub Repository](https://github.com/AIpourlapeau/acne04v2) and place into `Models/yolo/data/Acne04-v2_annotations.json`
* **Raw Images:** Download the ZIP Archive from the [Kaggle Dataset](https://www.kaggle.com/datasets/karmagames/acne04-v2) and extract it directly into `Models/yolo/data/`.


* **What it does:** Scans raw assets, maps circle coordinates to bounding boxes, splits data into Train (80%) / Val (10%) / Test (10%), fixes image name formatting errors, and separates completely unannotated images.
* **Expected Directory Structure:**

```
Models/
└── yolo/
    └── data/
        ├── Acne04-v2_annotations.json
        └── archive/
            └── img_data/
                └── img_data/
                    ├── levle0_0.jpg
                    └── ...

```

#### 5.1.2 Image Enhancement (`image_preprocess.py`)

**Command:** `python Models/yolo/src/image_preprocess.py`

* **Pre-requisite:** Complete step 5.1 so that `Models/yolo/data/Acne04_HD_YOLO_Filtered/` exists.
* **What it does:** Applies local contrast updates via optimized CLAHE parameters on the L and a* channels to highlight subtle acne lesions while preserving associated text labels and folder splits.
* **Output:** Creates the final augmented training bundle at `Models/yolo/data/final_dataset_preprocessed/`.

### 5.2 Training Options

Depending on your hardware, choose one of the methods below:

#### Option A: Local Training (`train.py`)
**Command:** `python Models/yolo/src/train.py`

* **What it does:** Starts the YOLOv8 training process with auto-GPU detection, optimized hyperparameters, and **Smart Resume**.
* **Result:** Copies the best weights to the **weights** folder upon completion.

#### Option B: Cloud Training - Google Colab (`yolo_training_colab.ipynb`)

**Location:** `Models/yolo/src/yolo_training_colab.ipynb`

* **What it does:** Designed for users with insufficient local hardware. Leverages Google Colab's T4 GPUs.
* **Key Feature:** Includes full **Hyperparameter Optimization (HPO)** via Optuna and auto-saves checkpoints directly to Google Drive.

#### Option C: Cloud Training - Kaggle Notebooks (`yolo_training_kaggle.ipynb`)

**Location:** `Models/yolo/src/yolo_training_kaggle.ipynb`

* **What it does:** Full Training & HPO pipeline optimized for Kaggle's dual-T4/P100 GPUs and temporary file system.

* **Prerequisites:** 
    * Turn on **Accelerator -> GPU** in Notebook Settings.
    * Add input dataset named `dataset_final_preprocessed` (with `train/`, `valid/`, `test/`, `data.yaml`).
    * *(Optional)* Add `acne_hparam_search_v3.2.db` to resume an Optuna search or `params-acne-hparam-search-v3-2-trial-14-yaml` to train model 3.2 with trial 14 parameters.

* **Execution:** Run setup, define functions, configure control flags (`RUN_HPARAM_SEARCH`, `RUN_PRODUCTION`) in `main()`, and execute.
* **Session Recovery:** Auto-resumes interrupted Optuna trials and YOLO training from `last.pt`.
* **Saving Results:** Run `export_runs_zip()` and `export_optuna()` before closing to download artifacts from the Output section. 

WARNING: Kaggle sessions have a strict timeout limit, and the /kaggle/working directory is completely temporary. If the session times out, closes, or disconnects before you export your data, all trained weights, logs, and database progress will be permanently lost. **Always download your files before closing the notebook**.

> Note: A detailed, step-by-step guide and complete environment configuration instructions are located directly inside the yolo_training_kaggle.ipynb notebook file.


### 5.3 Validation & Training Analysis

**Command:** `python Models/yolo/src/validate.py`

* **What it does:** Benchmarks the model, generating precision/recall plots and `results.json`.
* **Hyperparameter Optimization & Training Analysis:** For detailed performance tracking, HPO (Optuna) results, and historical training analysis, refer to the versioned notebooks (e.g. `yolo_analysis_v1.ipynb`). 

If you want to make your own analysis copy `yolo_analysis_v2.ipynb`.

### 5.4 Inference (`predict.py`)

**Command:** `python Models/predict.py --image path/to/image.jpg`

* **What it does:** Takes a photo and performs detection. It calculates a **Acne Score (0-1)** and saves an annotated image with a JSON report.
* **When to use:** For real-world testing.

# 6. YOLOv8 Windows + Conda + VS Code - Troubleshooting



### 6.1. Wrong Python Version (eg. 3.13 instead of 3.10)
**Symptom:** you tried `conda activate` and it runs, but `python --version` shows system Python.
**Fix (PowerShell):**
```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
conda init powershell
# Restart VS Code
```

---

### 6.2. ModuleNotFoundError (ultralytics)
**Symptom:** `import YOLO` fails.
**Fix (In active env):**
```bash
python -m pip install ultralytics
python -c "from ultralytics import YOLO; print('OK')"
```

---

### 6.3. Training Doesn't Start (No Epoch 1)
**Symptom:** Logs stop at `Plotting labels...`.
**Cause:** Wrong execution method or missing `if __name__ == "__main__":`.
**Fix:** Run manually in terminal: `python my_script.py` NOT with vs code "Run Python File".

---

### 6.4. OMP Error #15 (Crash)
**Symptom:** Immediate crash after starting training.
**Fix:** Add this to the very top of your `.py` file:
```python
import os
os.environ["KMP_DUPLICATE_LIB_OK"] = "TRUE"
```

# 7. Model Registry

Central system for tracking model versions, datasets, and performance benchmarks stored in **MODEL_REGISTRY.md**.

### Versioning Policy
**PATCH (v1.0.X)** -> Script/metadata fixes. No retraining.

**MINOR (v1.X)** -> New HParams, dataset expansion, preprocessing. Same architecture.

**MAJOR (vX.0)** -> Architecture change (e.g., v8n -> v8s, v8 - v11), new classes etc.
